Learning objectives and success criteria

  • Describe how an AI system follows a sequence of steps: input, process, output.
  • Use the input-process-output vocabulary accurately and connect it to building or evaluating a simple AI solution.

I can…

  • I can name the three stages of an AI workflow - input, process and output - in order.
  • I can trace a worked example and explain to a partner how the input became the output.
  • I can use the words input, process and output correctly when I talk about a solution.

Explanation and examples

An AI system is a pipeline. It takes an input (data such as text, an image or a number), runs a process (a trained model or s et of rules that transforms that input), and returns an output (a prediction, a label or generated content). The process stage is where a machine-learning model applies patterns it learned from many past examples; it does not think or understand, it maps inputs to likely outputs. The same three-stage shape describes almost every AI tool students meet, from a photo filter to a translation app. Making the stages visible helps learners reason about where an error can enter a workflow - a poor input, a limited process or a misread output - which is the foundation for evaluating and improving AI solutions later in the unit. The same shape in an everyday machine.

Source activity

Hands-on activity guide Overview: Students investigate three teacher-provided worked examples, map how each input becomes an output, and explain the reasoning to a partner. Grouping / timing: Pairs for the investigate and explain; whole class for the debrief. Tool: A teacher-operated board demo with a curated, pre-generated set of example outputs (no accounts, no live typing by students) - so the class studies safe, prepared results and no personal data is entered. Facilitation steps: 1. Look at the worked example your teacher shows on the board. 2. Find what goes in and write it next to Input. 3. Describe what happens inside and write it next to Process. 4. Find what comes out and write it next to Output. 5. Tell your partner how the input became the output, in order. 6. Check one output against the task - does it actually answer it? Unplugged fallback: Simulated-AI cards: a 'process' envelope holds a fixed rule (for example, match a word to a category). A student posts an input card in, the envelope returns the matching output card - the same three-stage shape with no device at all.
