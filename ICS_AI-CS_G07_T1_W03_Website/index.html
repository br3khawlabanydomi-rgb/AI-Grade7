Learning objectives and success criteria

  • Build a simple AI solution by following guided input-process-output steps.
  • Apply the workflow in a hands-on task and explain the reasoning behind the result.
  • Use the key vocabulary of AI solution design accurately and connect it to building or evaluating a solution.

I can…

  • I can build a simple AI workflow by following guided steps for input, process and output.
  • I can complete a hands-on task and explain why my workflow gave the result it did.
  • I can use words like input, process, output and workflow correctly when I talk about my solution.

Explanation and examples

A workflow is an ordered sequence of steps that turns an input into a useful output. In an AI solution at least one step is carried out by a model - for example classifying, sorting, summarising or generating. Building a simple solution at this level means composing steps in the right order, not training a model from scratch: the student decides what goes in, uses or is given the AI step, and defines what a good output looks like. Guided steps means the design is scaffolded by a template or a worked routine, with any tool use teacher-mediated. The skill being built is decomposition and sequencing - breaking a task into input, process and output, then checking that each step feeds the next so the whole workflow completes the task reliably. Verify before you trust: check every output against the task and a trusted source.

Source activity

Hands-on activity guide Overview: Pairs build and test a small three-step input-process-output workflow that completes one real class task, using a card-based simulated AI so no accounts or personal data are needed. Grouping / timing: Pairs for the build and test, whole class for the debrief. Tool: A simulated-AI card deck of pre-generated output cards prepared by the teacher stands in for the model step - account-free, no personal data, and it works even with no devices. If a device is used it is the school-approved tool, teacher-operated on the board only. Facilitation steps: 1. Choose one task from the task menu, for example sort six book titles into fiction and non-fiction. 2. Write your input in the first box - exactly what you will give the workflow. 3. Place the AI process card that matches your task in the middle box; this is the model step. 4. Draw the output the cards give you in the third box. 5. Run it again with a slightly different input and compare the two outputs. 6. Verify each output against the task and the trusted answer key, then tick or fix each box. Unplugged fallback: The whole activity is already unplugged using paper cards. For a fully human version, one student acts as the process and silently sorts the inputs by a rule the pair wrote, while the others check the output.
